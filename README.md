# Supermarket Management Website

## 📌 Project Overview

The Supermarket Management Website is a web-based application developed to streamline supermarket operations and enhance the customer shopping experience. The platform provides separate functionalities for customers, managers, and administrators.

## 🚀 Features

### Customer Features

* User Registration & Login
* Browse Products
* Search and Filter Products
* Add Products to Cart
* Place Orders
* View Order History

### Manager/Admin Features

* Secure Authentication
* Product Management
* Inventory Tracking
* Customer Management
* Order Management
* Sales Monitoring
* Dashboard Analytics

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Local Storage / Database
* Responsive Design

## 🎯 Objectives

* Digitize supermarket operations.
* Improve inventory management.
* Simplify customer purchasing processes.
* Provide an efficient management dashboard.
* Enhance overall business productivity.

## 📸 Main Modules

* Authentication System
* Customer Portal
* Product Catalog
* Shopping Cart
* Inventory Management
* Order Management
